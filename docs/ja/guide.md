# <i class="bi bi-mouse2-fill"></i>   使い方
当アドオンは４つの機能を搭載しており5つのセクションに分かれています。
レンダーエンジンはEEVEEのみ対応しています。
当アドオンで5つのステップで漫画のシーンの土台を整えることができます。

![3D漫画スタジオの画面](assets/img/JP/side pannel.png)

### 1. 3D漫画コレクションを生成   <i class="bi bi-archive-fill"></i>
漫画のシーンに効果的なコレクションを自動でセットアップするメニューです。

### 2. カメラ設定   <i class="bi bi-camera-fill"></i>
レンダリング（出力）するシーンサイズ、パース（焦点距離）を簡単に設定でき、セーフエリア、ガイドの表示/非表示を切り替えるメニューです。

### 3. マテリアルとアウトライン生成   <i class="bi bi-box-fill"></i>
専用マテリアル「Manga Tone Shader」と アウトラインを選択したオブジェクトに適用するメニューです。

### 4. ライトコレクション管理   <i class="bi bi-lightbulb-fill"></i>
専用のライトオブジェクトをグループごとに管理するメニューです。

### 5. Manga Tone Shader   <i class="bi bi-noise-reduction"></i>
Manga Tone Shader のプロパティを自由に調整するメニューです。

![Manga Tone Shaderのプロパティ画面](assets/img/JP/MTS pannel.png)
