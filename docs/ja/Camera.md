# <i class="bi bi-camera-fill"></i>  カメラ設定
![カメラ方式のセクション](assets/img/JP/camera section.png)

次にカメラの設定方法について説明します。

## <i class="bi bi-journal-richtext"></i>  操作手順

### カメラ方式
![カメラ方式のセクション](assets/img/JP/camera type.png)

カメラ方式には奥行きを表現する「透視投影」とアイソメトリックなどの平面表現が可能な「平行投影」の2種類があります。
 
- 透視投影: アクションシーンや風景の描写に適しており、遠近感を強調できます。

    ![透視投影時の画面](assets/img/JP/camera perse.png)

- 平行投影: 上から写す風景や横から写すキャラクター・背景の描写に適しており、遠近感がないため、デフォルメされた表現が可能です。

    ![平衡投影時の画面](assets/img/JP/camera orthographic.png)

### 焦点距離・視界のスケール   <i class="bi bi-patch-check-fill">NEW@1.0.1</i>
焦点距離はパースの強さを調整します。焦点距離が短いほどパースが強くなり、長いほどパースが弱くなります。
視界のスケールは、拡大率を調整します。拡大するほど表示範囲が狭くなり、縮小するほど表示範囲が広くなります。

![焦点距離のプロパティ](assets/img/JP/camera scale perse.png)
![視界のスケールのプロパティ](assets/img/JP/camera scale orthographic.png)

### カメラサイズ
![カメラサイズのセクション](assets/img/JP/camera size.png)

出力するシーンのサイズ（レンダリングサイズ）を設定します。一般的な漫画のサイズに合わせたプリセットを用意しています。

- 解像度 X: 出力するシーンの横幅をピクセル単位で指定します。
- 解像度 Y: 出力するシーンの縦幅をピクセル単位で指定します。
- 割合: 出力するシーンの解像度を指定します。%が高いほど高解像度になります。
- プリセット: 一般的な漫画のサイズに合わせたプリセットを選択できます。

    ![カメラプリセット選択時の画面](assets/img/JP/camera size presets.png)

- セーフエリア: 出力するシーンのセーフエリアを表示/非表示に切り替えます。セーフエリアは、印刷時に重要な要素が切れないようにするためのガイドラインです。セーフエリアを有効時に以下の項目を設定できます。
  
    ![セーフエリア表示時の画面](assets/img/JP/camera safearea.png)
    
    1. セーフエリア方式: セーフエリアの値の指定方法を「均一」か「分離」から選択できます。
        ![セーフエリア方式選択時の画面](assets/img/JP/camera type select.png)

        1. 均一: 上下左右すべて同じ値を設定します。

            ![セーフエリア均一時の画面](assets/img/JP/camera type uniform.png)

            - マージン（px）: セーフエリアのガイドラインをカメラ領域（レンダー領域）の端からどれだけ内側に設定するかをピクセル単位で指定します。

        2. 分離: 上下・左右それぞれ別々の値を設定します。

            ![セーフエリア分離時の画面](assets/img/JP/camera type separate.png)

            - 左右マージン（px）： セーフエリアのガイドラインをカメラ領域（レンダー領域）の左右端からどれだけ内側に設定するかをピクセル単位で指定します。
            - 上下マージン（px）： セーフエリアのガイドラインをカメラ領域（レンダー領域）の上下端からどれだけ内側に設定するかをピクセル単位で指定します。

    2. ライン幅: セーフエリアのガイドラインの太さを調整できます。

        ![セーフエリアラインの太さの調整比較の画面](assets/img/JP/camera safearea width.png)

    3. カラー: セーフエリアのガイドラインの色を調整できます。アルファ値（透明度）も調整可能です。

        ![セーフラインのカラーの調整比較の画面](assets/img/JP/camera safearea color.png)

### レイアウトガイドライン
![レイアウトガイドラインを表示時の画面](assets/img/JP/camera layout.png)

レイアウトガイドラインの表示/非表示を切り替えます。ガイドラインは、コマ割りやキャラクターの配置を補助するためのガイドです。
有効にすると以下のガイドラインが表示されます。

- 列ガイド: シーンを縦に分割するガイドラインを表示します。列数を2から100列まで選択できます。

    ![列ガイド調整比較の画面](assets/img/JP/camera layout  column.png)

- 行ガイド: シーンを横に分割するガイドラインを表示します。行数を2から100列まで選択できます。

    ![行ガイド調整比較の画面](assets/img/JP/camera layout  row.png)
 
- ガイド線の太さ: ガイドラインの太さを調整できます。

    ![ガイド線の調整比較の画面](assets/img/JP/camera layout  width.png)

- ガイド色: ガイドラインの色を調整できます。アルファ値（透明度）も調整可能です。

    ![ガイド色の調整比較の画面](assets/img/JP/camera layout color.png)
