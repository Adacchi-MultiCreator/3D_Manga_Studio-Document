# <i class="bi bi-archive-fill"></i>  3D漫画コレクションを作成
![３D漫画コレクションを生成のセクション](assets/img/JP/3d collection section.png)

まず最初に、作品用のシーン構造を自動で作りましょう。

## <i class="bi bi-journal-richtext"></i>  操作手順
1. ++n++を押してBlenderの右側の「サイドパネル」（Nパネル）を開きます。
2. 「3D漫画スタジオ」タブを選びます。
3. 「3D漫画コレクションを作成」のボタンをクリックします。
4. 既存のコレクション（アウトライナー）を削除するかどうかの確認ダイアログが表示されます。必要に応じて選択してください。

	![3D漫画コレクション生成の確認画面](assets/img/JP/collection dialog.png)
	!!! warning "注意"
		ダイアログで既存のコレクションをクリアにチェックを入れた場合、現在のシーン内のすべてのコレクションとオブジェクトが削除されます。必要なデータがある場合は、チェックを外してください。

5. 以下のようなコレクション構造が自動で作成されます。
 
	![3D漫画コレクション生成後の画面](assets/img/JP/collection generated.png)
	!!! note "カメラについて"
		カメラが自動で最適な位置・角度で設置されるため、構図作りがすぐに始められます。
