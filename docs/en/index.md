## <i class="bi bi-flag-fill"></i>  Welcome to 3D Manga Studios
3D Manga Studios is a helper tool for Blender that efficiently and faithfully reproduces manga/comic-like rendering on objects you create.

## <i class="bi bi-pin-angle-fill"></i>  Features

### 1. Automatic collection setup   <i class="bi bi-archive-fill"></i>
Creates an outliner (collection structure) optimized to manage four core features with a single click.

### 2. Intuitive camera controller   <i class="bi bi-camera-fill"></i>
Easily set scene size and perspective (focal length). Safe areas and guides help you compose shots effectively.

### 3. One-click material and outline generation   <i class="bi bi-box-fill"></i>
Apply the included Manga Tone Shader and an extracted outline to selected objects with just two buttons.

### 4. Auto placement of dedicated lights   <i class="bi bi-lightbulb-fill"></i>
Quickly place a group of three lights (key, fill, back) designed for Manga Tone Shader with a single click.

### 5. Manga-focused shader and control panel   <i class="bi bi-noise-reduction"></i>
The included Manga Tone Shader makes it easy to create authentic manga tones, such as high-contrast shadows and tone patterns applied only in shadowed regions.
