# <i class="bi bi-translate"></i>   Translation
The 3D Manga Studios add-on uses Blender’s built-in translation system to support Japanese and English. The UI and descriptions switch automatically based on Blender’s language settings.

## <i class="bi bi-table"></i>   Translation table
We support translations for menu labels, popup messages, and Manga Tone Shader parameters. See the tables below for mapping.
