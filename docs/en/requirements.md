# <i class="bi bi-cpu-fill"></i>   Requirements
This add-on works in the following environments.

## <i class="bi bi-laptop-fill"></i>   Supported software
- OS: Windows 10/11, macOS 13.0+

- Blender version: 4.5 or later (4.4 is usable but some operations will be unavailable.)

Note: Experimental builds are not supported.

## <i class="bi bi-laptop-fill"></i>   Render engine
- EEVEE

## <i class="bi bi-gear-wide-connected"></i>   Graphics Display Backend
- OpenGL
!!! warning "Notes"
	- Install the latest graphics drivers to ensure optimal performance.
	- OpenGL is recommended. Vulkan may cause some features to malfunction and can lead to freezes or crashes.
