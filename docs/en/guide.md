# <i class="bi bi-mouse2-fill"></i>   How to use
The add-on provides four functions organized into five sections. It supports only the EEVEE render engine.
With five steps, you can set up a base for your manga scene.

![3D Manga Studios UI](assets/img/EN/side pannel.png)

### 1. Generate 3D Manga Collection   <i class="bi bi-archive-fill"></i>
Automatically set up an effective collection structure for manga scenes.

### 2. Camera Settings   <i class="bi bi-camera-fill"></i>
Easily set render size and perspective (focal length), and toggle safe areas and guides.

### 3. Material & Outline Generation   <i class="bi bi-box-fill"></i>
Apply the dedicated Manga Tone Shader and outline to selected objects.

### 4. Light Collection Management   <i class="bi bi-lightbulb-fill"></i>
Manage dedicated light objects by groups.

### 5. Manga Tone Shader   <i class="bi bi-noise-reduction"></i>
Adjust Manga Tone Shader properties freely.

![Manga Tone Shader properties](assets/img/EN/MTS pannel.png)
